Cegah & Tangani Karhutla

Pencegahan

Jangan membakar sampah atau lahan, padamkan puntung rokok, dan jangan berkemah dengan api terbuka saat kemarau.

Kenali tanda awal

Asap tipis di semak kering, bau terbakar, atau burung dan satwa yang turun mendadak dari hutan.

Waspada musim kemarau

Suhu tinggi, kelembapan rendah, dan angin kencang membuat api cepat menyebar.

Jika melihat api

  1. Jauhi api dan jangan memadamkan sendiri bila api besar.
  2. Ambil foto dari jarak aman dan bagikan titik lokasi.
  3. Kirim laporan di halaman Lapor.
  4. Hubungi Damkar atau MPA, lalu peringatkan warga sekitar.
  5. Siapkan jalur evakuasi dan jauhi arah angin.

Tentang SiagaApi

Sistem peringatan dini karhutla berbasis warga untuk Desa Gedong, Kab. Semarang. Data cuaca dari BMKG. Level risiko adalah indeks sederhana (suhu, kelembapan, angin, dan laporan warga), bukan status resmi BMKG atau KLHK. Foto latar bersumber dari Wikimedia Commons. Dalam keadaan darurat, utamakan telepon ke petugas.
